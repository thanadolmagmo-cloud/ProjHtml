โปรเจกต์รายวิชา การเขียนโปรแกรมบนเว็บ 1/2569 — ระบบสารสนเทศท่องเที่ยวและสินค้าชุมชน จังหวัดหนองคาย

วิธีติดตั้ง (XAMPP)
1. คัดลอกโฟลเดอร์ nongkhai ไปไว้ใน htdocs  (เช่น C:\xampp\htdocs\nongkhai)
2. เปิด Apache และ MySQL ใน XAMPP
3. phpMyAdmin > แท็บ Import > เลือกไฟล์ sql/database.sql > Go
   (ไฟล์นี้สร้างฐานข้อมูล nongkhai, ตารางทั้งหมด, ข้อมูลสถานที่ 21 แห่ง, สินค้า 3 รายการ และบัญชี admin)
4. เปิด http://localhost/nongkhai/index.php

บัญชีทดสอบ
- ผู้ดูแลระบบ : admin / admin1234   (เปลี่ยนรหัสผ่านได้ที่เมนู "เปลี่ยนรหัสผ่าน")
- สมาชิก      : สมัครเองที่หน้า "สมัครสมาชิก"

ถ้าตั้งรหัสผ่าน MySQL หรือใช้ชื่อฐานข้อมูลอื่น ให้แก้ที่ connect.php

การนำขึ้นโฮสติ้ง: อัปโหลดทุกไฟล์ (รวมโฟลเดอร์ uploads) ขึ้นเซิร์ฟเวอร์, Import database.sql ในฐานข้อมูลของโฮสต์ แล้วแก้ host/user/pass/dbname ใน connect.php
(ถ้าโฮสต์ไม่ให้สร้างฐานข้อมูลเอง ให้ลบสองบรรทัด CREATE DATABASE และ USE ออกจาก database.sql ก่อน Import)

ตารางสิทธิ์การใช้งาน
- ผู้ใช้ทั่วไป : ดูข้อมูลทั่วไปของจังหวัด (หน้าแรก), สมัครสมาชิก
- สมาชิก      : login, เปลี่ยนรหัสผ่าน, ดูข้อมูลจังหวัด, ค้นหา/ดูสถานที่ (กรองตามประเภท/อำเภอ), ค้นหา/ดูสินค้าชุมชน, เปิดตำแหน่งบน Google Maps
- ผู้ดูแลระบบ  : login, เปลี่ยนรหัสผ่าน, เพิ่ม/ลบ/แก้ไข/ค้นหา ประเภทสถานที่, สถานที่ และสินค้าชุมชน (อัปโหลดรูปได้หลายรูป)

หมายเหตุ: ช่อง "พิกัด" ของสถานที่เก็บเป็นลิงก์ Google Maps (เช่น https://maps.app.goo.gl/xxxx) ไม่ใช้ละติจูด/ลองจิจูดแล้ว
ส่วนสินค้าชุมชนใส่ลิงก์พิกัดผู้ผลิตไว้ในรายละเอียด ระบบจะแสดงเป็นลิงก์กดได้อัตโนมัติ
